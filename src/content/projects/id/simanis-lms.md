Sistem manajemen pembelajaran untuk SMK Mataram yang mencakup siswa, guru, mata pelajaran, modul, dan bimbingan konseling. Dibangun di atas Bun, Elysia, dan Drizzle dengan front end Next.js 15 dan autentikasi JWT berbasis role.

Proyek tim untuk mata kuliah Rekayasa Perangkat Lunak — REST API dengan CRUD lengkap untuk auth, mata pelajaran, dan modul, endpoint berbasis role untuk admin / guru / siswa, plus dashboard per role.
