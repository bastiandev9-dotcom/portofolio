Alat blur latar webcam real‑time menggunakan vanilla JavaScript dan Canvas API. Terapkan Gaussian blur pada video, atur radius blur dengan slider, dan unduh hasilnya.

Tanpa library eksternal — hanya getUserMedia dan operasi canvas 2D. Berjalan sepenuhnya di browser.
