Toko e-commerce parfum berbasis PHP native dan MySQL dengan 19 tabel — katalog produk dengan filter dan sorting, keranjang, checkout dengan kurir dan kode promo, pelacakan pesanan via kode order, plus panel admin lengkap dengan laporan penjualan, update status pesanan, dan export CSV/PDF.

Autentikasi memakai bcrypt dengan reset password berbasis token. Semua berjalan di XAMPP tanpa framework.
