A Streamlit chatbot for discovering and registering for events and conferences. Instead of a model, it matches user intent with a modular regex rule engine, then queries mock event data stored in JSON.

Built for a Software Engineering course (TBO) project. The bot handles event search, detail lookup, and registration flow with in-session state.
