Chatbot Streamlit untuk mencari dan mendaftar event serta konferensi. Alih-alih model, bot mencocokkan maksud pengguna lewat aturan regex yang modular, lalu mengambil data event mock dari JSON.

Dibangun untuk proyek mata kuliah Rekayasa Perangkat Lunak (TBO). Bot menangani pencarian event, detail event, dan alur pendaftaran dengan state di sesi.
