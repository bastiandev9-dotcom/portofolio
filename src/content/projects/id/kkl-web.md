Website resmi KKL Karang Taruna dengan fitur kalender acara dinamis, direktori anggota, dan sistem pengumuman. Dibuat menggunakan Next.js App Router, server actions untuk formulir, dan PostgreSQL untuk penyimpanan data.

Termasuk dashboard admin untuk mengelola acara dan anggota, desain responsif dengan Tailwind.
